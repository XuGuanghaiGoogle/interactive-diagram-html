## 画布与网格

- 画布宽度取 1700～1800，高度按内容定，最后留 20～40 的余量。
- 用固定列距排列节点：`列 i 的 x = x0 + i × pitch`，节点宽度 = `pitch − 30`（容器型）或 `pitch − 40`（时间轴型）。**两列之间留出的空隙就是走线的通道**，这是整张图不乱的关键。
- 同一行的节点用同一个 y，行距至少为节点高度加 14。
- 分组框的左上角约 24px 被标签占用，节点离框顶至少 30px，离左右边至少 16px。

## 容器型（构成图）

参考尺寸（1780 × 1300）：

| 区域 | x 范围 | 内容 |
| --- | --- | --- |
| 外部 / 利用者 | 30～260 | 节点 190 × 54 |
| 云账号 / 平台 | 290～1320 | 内部再分网络、存储、共通服务等子框 |
| 另一平台（例如 SaaS 控制平面） | 1340～1740 | 节点 364 × 58，纵向排列，间距 73 |
| 运维带 | 290～1740，底部 | 节点 335～340 × 64，每行 4 个 |

子框内部分两列：`x = 框x + 32` 和 `框x + 32 + 320`，节点宽 300。两列之间 20px 的空隙用来走竖线。

## 带状型（处理流程图）

- 泳道横跨整个画布（x 20～1700），列公式 `COL(i) = 50 + (i−1) × 180`，节点宽 150，共 9 列。
- 泳道内分 1～3 行。竖着排的并列节点（例如 4 路并行检索），y 间隔取 60。
- 存储带：7 个圆柱，宽 210、间距 22，横向铺开。写入存储时，从上方的汇流线（bus，比泳道底边低 18px 左右的一条水平线）分别下落到各存储。

## 时间轴型（开发计划）

```text
timeline: x0 = 200, colW = 260, y = 60, h = 36
第 c 列（从 0 开始）的节点：x = x0 + c·colW + 20，宽 = 跨列数·colW − 40
泳道高 150：A 行 y = 泳道y + 34，B 行 y = 泳道y + 92，节点高 50
里程碑菱形：中心放在 Sprint 交界线（x0 + k·colW）上，宽 150、高 70
```

- 泳道标签画在 x 20～200 之间，节点从 x0 开始放，二者不会重叠。
- 泳道的 fill 使用带透明度的颜色，否则会盖住时间轴网格。
- 依赖线的竖直段放在两列交界处（列边界 ± 0～10px）。多条线挤在同一个空隙里时，把 mx 错开 8～10px（例如 1232 / 1240 / 1250）。

## 走线规则

1. **只走空隙**：`r→l` 连线的 `mx` 取两列之间空隙的中线；`b→t` 连线的 `my` 取两行之间空隙的中线。
2. **长距离的回流线**绕到画布边缘的通道：左边 x≈34，右边取画布宽度减去 20～90。
3. **多条线接到同一个端口**时，用 `d1`、`d2` 在 ±12～16 的范围内错开，并把拐点改到各自不同的通道上。
4. **总线（bus）**：从一个节点连到多个节点时，让所有连线共用同一段竖线和同一段横线，只在最后分别下落。共线重叠的部分看起来就像一条线，是可以接受的。
5. **via** 拐点一定要让每一段都保持水平或竖直，否则校验会报"不是直角走线"。
6. 与其画一条绕远的线，不如用 `uses`（圆点加面板里的关联）表达关系。存储之类被多处引用的节点尤其适合这样处理。

## 标签

- 标签控制在 12 个字以内。
- 放在不压节点的那一段上。先试 `lp`（线段序号）；如果还是压到节点，就用 `lx`、`ly` 直接指定坐标。
- 竖直段上的标签，宽度会横跨空隙。遇到窄的空隙，把标签放到上方或下方的横向空白里。

## 校验警告对照

| 警告 | 修法 |
| --- | --- |
| 节点重叠 | 按网格公式重新计算 x / y；同一列的节点，y 至少相差（节点高 + 14） |
| 连线穿过节点 | 把 `mx` / `my` 改到空隙的中线；实在不行，加 `via`，从外侧通道绕开；或者删掉这条线，改用 `uses` |
| 不是直角走线 | 检查 `via`，给相邻的两个点补齐相同的 x 或 y |
| 标签压在节点上 | 用 `lx` / `ly` 把标签挪到空白处，或者改短文字 |
| 文字即使缩到 8px 仍放不下 | 缩短 `d` 的文字（详细内容写进面板），或者加宽节点 |
| 高度放不下 N 行文字和标记 | 加高节点，或者把 `d` 减到 2 行 |
| 超出画布 | 调整坐标，或者加大 `canvas` |
| 没有 role / fn，点击不会打开面板 | 补上内容；如果是纯说明框，改成 `shape: "note"` |
| fn 只有 N 条 | 补到 4 条以上，写具体内容 |
