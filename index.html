Diagrams you can click, read and rearrange

A Claude Code skill that turns architecture diagrams, process flows and development plans into a single interactive HTML file through a guided conversation. Click any block to read its role, functions and scope; drag blocks and draw lines when you want to adjust the layout yourself.

The demos below are in Japanese. Pages can be generated in English, Japanese or Chinese.

What you get

  • One HTML fileNo external resources. Send it by mail or drop it on a shared drive.
  • Details on clickEach block opens a panel with role, functions, screens and scope.
  • Checked layoutThe build script flags overlapping blocks, lines through blocks and broken IDs.
  • Optional editingDrag, resize and connect in the browser, then save back to the data JSON locally.
  • Workload per phaseDevelopment plans can show features, screens and effort per phase as a chart.
  • Three languagesUI text in English, Japanese or Chinese.

Install in Claude Code

/plugin marketplace add XuGuanghaiGoogle/interactive-diagram-html
/plugin install interactive-diagram-html@interactive-diagram-html

Then describe what you need, for example: “Turn this repository into an architecture diagram and mark the PoC scope.” Requires Node.js 18 or later. Works with Codex and other agents too — see the README.
